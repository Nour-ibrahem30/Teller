# Teller (تيلر)

**قصة تصل وتؤثر.**

Egyptian storytelling and branding company.

---

## 🚀 V1 Website Prototype

A fully functional, presentation-ready website prototype built with Next.js, TypeScript, and Tailwind CSS.

### Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

**Visit:** http://localhost:3000

---

## 🌐 Deployment (Vercel)

This project is optimized for deployment on [Vercel](https://vercel.com).

### Deploy Steps

1. Push the repository to GitHub.
2. Go to [vercel.com/new](https://vercel.com/new) and import the `Teller` repository.
3. Vercel auto-detects Next.js — no extra configuration needed.
4. Click **Deploy**.

### Build Settings (auto-detected)

| Setting | Value |
|---------|-------|
| Framework Preset | Next.js |
| Build Command | `npm run build` |
| Output Directory | `.next` |
| Install Command | `npm install` |
| Node Version | 18.x+ |
