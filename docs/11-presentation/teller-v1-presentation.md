## 1. Creative Concept — المفهوم الإبداعي

### The Big Idea: "A Website That Tells Its Own Story"

الموقع لا يشرح فقط أن تيلر متخصصة في السرد القصصي — بل يُظهر ذلك من خلال:

- **البنية السردية:** الصفحة الرئيسية مبنية كقصة متدرجة
- **التدفق العاطفي:** من المشكلة → للإلهام → للحل → للدعوة للعمل
- **التايبوجرافي:** استخدام الخط العربي بشكل معبر وواضح

### Narrative Flow (Homepage)

```
المشهد الافتتاحي (Hero)
    ↓
المشكلة (كتير براندات عندها قصص بس مش بتتوصل)
    ↓
الإلهام (الناس بتتواصل مع قصص مش إعلانات)
    ↓
مين تيلر؟
    ↓
خدماتنا
    ↓
طريقتنا (ابتكار - سرد - تأثير)
    ↓
ليه السرد القصصي؟
    ↓
دعوة للعمل النهائية
```

## 3. UX Strategy — استراتيجية تجربة المستخدم

### User Goals

1. **فهم ما تقدمه تيلر** — خلال أول 10 ثواني
2. **اكتشاف الخدمات** — بشكل سلس وواضح
3. **التواصل بسهولة** — CTA واضح في كل صفحة

### Conversion Strategy

- **Primary CTA:** "احكيلنا حكايتك" (يظهر في Header و Hero)
- **Secondary CTA:** "اكتشف تيلر" (استكشاف الموقع)
- **كل صفحة تنتهي بـ CTA** للتحويل

### Navigation Design

```
الرئيسية | حكايتنا | خدماتنا | طريقتنا | تواصل معنا | [احكيلنا حكايتك]
```

- Navigation ثابت أثناء التمرير
- Mobile menu كامل مع animations
- Accessible (keyboard navigation)

## 4. Visual System — النظام البصري

### Design Principles

1. **Storytelling First** — التصميم يدعم السرد
2. **Arabic Typography** — الخط العربي هو البطل
3. **Generous Whitespace** — مساحات بيضاء واسعة
4. **Subtle Motion** — حركة هادفة ومحسوبة
5. **Accessible** — متاح للجميع

### Typography Scale

- **Hero Headline:** 4rem - 7rem (متجاوب)
- **Section Headlines:** 2.25rem - 3.75rem
- **Body Large:** 1.25rem - 1.5rem
- **Body:** 1rem - 1.125rem

### Component System

تم بناء نظام مكونات قابل لإعادة الاستخدام:

- Navigation (مع حالة mobile)
- Hero sections
- Service cards
- CTA sections
- Footer
- Button variants (primary, secondary, ghost)

## 5. Business Value — القيمة التجارية

### كيف يدعم الموقع أهداف تيلر

1. **بناء المصداقية**
   - تصميم احترافي يعكس جودة الخدمات
   - نهج قصصي يُظهر الخبرة

2. **جذب العملاء**
   - رسالة واضحة للجمهور المستهدف
   - CTAs متعددة للتحويل

3. **عرض الخدمات**
   - تقديم الخدمات بطريقة واضحة وجذابة
   - ربط كل خدمة بالمشكلة التي تحلها

4. **التميز عن المنافسين**
   - تجربة فريدة (ليس template عادي)
   - هوية بصرية متسقة ومميزة

## 8. Pending Decisions — قرارات معلقة

### تحتاج تأكيد فوري

| البند | الحالة الحالية | المطلوب |

- هل محتوى الصفحات يعكس صوت تيلر بشكل صحيح؟
- هل ترتيب الخدمات صحيح؟
- هل منهجية "ابتكار-سرد-تأثير" مفسرة بشكل صحيح؟
- هل هناك خدمات إضافية يجب إضافتها؟
